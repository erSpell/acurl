# acurl

See your website the way AI agents see it. This package installs the
[acurl](https://acurl.dev) CLI, a free, open-source tool by [tragent.io](https://tragent.io).

```bash
pipx install acurl
acurl https://yourstore.com
```

On first run it downloads the prebuilt binary for your platform from
[GitHub Releases](https://github.com/tragent-io/acurl/releases), verifies it against the
release's SHA-256 checksums and caches it. Documentation: https://acurl.dev/docs/
