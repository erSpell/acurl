Everything here runs locally with the acurl CLI.

# one page, every agent
acurl yourstore.com/products/1
# only AI assistants, fail CI below 80
acurl --category ai-assistant --fail-on score<80 yourstore.com
# robots.txt, content signals and llms.txt
acurl robots yourstore.com
# every URL in your sitemap
acurl batch --sitemap auto:yourstore.com --limit 50

JSON API

The page uses this API. Your own tools can use it too.

curl -s -X POST localhost:8080/api/check \
  -d '{"url":"yourstore.com","categories":["ai-assistant"]}'

# also:
GET  /api/check/stream?url=...   # live progress
GET  /api/robots?url=...
GET  /api/profiles
POST /api/report?format=html

acurl sends agent user-agent strings from this machine's IP address. Real agents come from published IP ranges and may sign their requests.

acurl.dev is a free, open-source tool by tragent.io.
