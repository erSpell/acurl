# Examples

Ready-to-copy setups for acurl, a free, open-source tool by [tragent.io](https://tragent.io).

| Example | What it shows |
|---|---|
| [github-actions/pull-request.yml](github-actions/pull-request.yml) | Fail pull requests when AI assistants lose access |
| [github-actions/nightly.yml](github-actions/nightly.yml) | Nightly sitemap check with SARIF, plus an HTML report artifact |
| [gitlab-ci/.gitlab-ci.yml](gitlab-ci/.gitlab-ci.yml) | JUnit results in GitLab merge requests |
| [config/.acurl.yaml](config/.acurl.yaml) | A project config file |
| [config/profiles.yaml](config/profiles.yaml) | A custom agent profile catalog |
| [cron/acurl-watch.sh](cron/acurl-watch.sh) | Hourly watch with Slack alerts |
| [mcp/claude_desktop_config.json](mcp/claude_desktop_config.json) | acurl as an MCP server in Claude Desktop |
| [library/main.go](library/main.go) | Using the Go API |
